NC News API

REST API for a news application. This documentation describes available endpoints, queries, request bodies and example responses.

This page is served statically at /api. JSON documentation is available at /api/endpoints.

Overview

Base path: /api

All responses are returned in JSON format.

Common response shapes

  • { "topics": [...] }
  • { "users": [...] }
  • { "articles": [...] }
  • { "article": {...} }
  • { "comments": [...] }
  • { "comment": {...} }
  • { "msg": "..." } for errors

Timestamps

Date fields (e.g. created_at) are returned as ISO strings, for example: 2020-11-03T09:12:00.000Z.

GET /api/endpoints

Returns a JSON object describing all available API endpoints.

Example response

{
  "endpoints": {
    "GET /api/topics": {
      "description": "Returns all topics"
    }
  }
}

Topics

GET /api/topics

Returns a list of all topics.

Example response

{
  "topics": [
    {
      "slug": "mitch",
      "description": "All about Mitch",
      "img_url": "..."
    }
  ]
}

Users

GET /api/users

Returns a list of all users.

Example response

{
  "users": [
    {
      "username": "butter_bridge",
      "name": "Jonny",
      "avatar_url": "https://..."
    }
  ]
}

Articles

GET /api/articles

Returns a list of articles. Articles are sorted by created_at in descending order by default.

Queries

  • sort_by – column to sort by (default: created_at)
  • order – asc or desc (default: desc)
  • topic – filters articles by topic

Example response

{
  "articles": [
    {
      "author": "butter_bridge",
      "title": "Living in the shadow of a great man",
      "article_id": 1,
      "topic": "mitch",
      "created_at": "2020-07-09T20:11:00.000Z",
      "votes": 100,
      "article_img_url": "https://...",
      "comment_count": 11
    }
  ]
}

GET /api/articles/:article_id

Returns a single article by ID, including comment_count.

Example response

{
  "article": {
    "article_id": 1,
    "title": "Living in the shadow of a great man",
    "author": "butter_bridge",
    "body": "I find this existence challenging",
    "topic": "mitch",
    "created_at": "2020-07-09T20:11:00.000Z",
    "votes": 100,
    "article_img_url": "https://...",
    "comment_count": 11
  }
}

GET /api/articles/:article_id/comments

Returns comments for a given article.

Example response

{
  "comments": [
    {
      "comment_id": 1,
      "votes": 16,
      "created_at": "2020-04-06T12:17:00.000Z",
      "author": "butter_bridge",
      "body": "Great article!",
      "article_id": 1
    }
  ]
}

POST /api/articles/:article_id/comments

Adds a new comment to an article.

Request body

{
  "username": "butter_bridge",
  "body": "Nice read!"
}

Example response

{
  "comment": {
    "comment_id": 999,
    "article_id": 1,
    "author": "butter_bridge",
    "body": "Nice read!",
    "votes": 0,
    "created_at": "2026-02-09T10:00:00.000Z"
  }
}

PATCH /api/articles/:article_id

Updates an article’s vote count.

Request body

{
  "inc_votes": 1
}

Comments

DELETE /api/comments/:comment_id

Deletes a comment by ID.

Responds with status 204 and no content.

Error handling

  • 400 – Bad request
  • 404 – Resource not found
  • 500 – Internal server error

Example error

{
  "msg": "Bad request"
}
