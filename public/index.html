NC News API

REST API for a news application. This documentation describes available endpoints, queries, request bodies and example responses.

This page is served statically at /api. JSON documentation is available at /api/endpoints.

Overview

  • Base path: /api
  • All endpoints return JSON responses
  • Static HTML docs: /api · Endpoints JSON: /api/endpoints

Common response shapes

  • { "topics": [...] }
  • { "users": [...] }
  • { "user": {...} }
  • { "articles": [...] }
  • { "article": {...} }
  • { "comments": [...] }
  • { "comment": {...} }
  • { "msg": "..." } for errors

Timestamps

Date fields (e.g. created_at) are returned as ISO strings, for example: 2020-11-03T09:12:00.000Z.

Endpoints JSON

GET /api/endpoints

Returns a JSON object describing all available API endpoints.

Example response

{
  "endpoints": {
    "GET /api/topics": {
      "description": "Returns all topics"
    }
  }
}

Topics

GET /api/topics

Returns a list of all topics.

Example response

{
  "topics": [
    {
      "slug": "mitch",
      "description": "All about Mitch",
      "img_url": "..."
    }
  ]
}

Users

GET /api/users

Returns a list of all users.

Example response

{
  "users": [
    {
      "username": "butter_bridge",
      "name": "Jonny",
      "avatar_url": "https://..."
    }
  ]
}

GET /api/users/:username

Returns a single user by username.

Path params

  • username – the username of the user

Example response

{
  "user": {
    "username": "butter_bridge",
    "name": "Jonny",
    "avatar_url": "https://..."
  }
}

Errors

  • 404 – { "msg": "User not found" }

Articles

GET /api/articles

Returns a list of articles. Articles are sorted by created_at in descending order by default.

Queries

  • sort_by – column to sort by (default: created_at)
  • order – asc or desc (default: desc)
  • topic – filters articles by topic
  • limit – number of articles per page (default: 10)
  • p – page number (default: 1)

Example requests

  • /api/articles?limit=5&p=1
  • /api/articles?topic=mitch&limit=5&p=2
  • /api/articles?sort_by=votes&order=asc

Example response

{
  "total_count": 13,
  "articles": [
    {
      "author": "butter_bridge",
      "title": "Living in the shadow of a great man",
      "article_id": 1,
      "topic": "mitch",
      "created_at": "2020-07-09T20:11:00.000Z",
      "votes": 100,
      "article_img_url": "https://...",
      "comment_count": 11
    }
  ]
}

Errors

  • 400 – { "msg": "Bad request" } (invalid queries)
  • 404 – { "msg": "Topic not found" } (topic filter does not exist)

GET /api/articles/:article_id

Returns a single article by ID, including comment_count.

Path params

  • article_id – the id of the article

Example response

{
  "article": {
    "article_id": 1,
    "title": "Living in the shadow of a great man",
    "author": "butter_bridge",
    "body": "I find this existence challenging",
    "topic": "mitch",
    "created_at": "2020-07-09T20:11:00.000Z",
    "votes": 100,
    "article_img_url": "https://...",
    "comment_count": 11
  }
}

Errors

  • 400 – { "msg": "Bad request" } (invalid article_id)
  • 404 – { "msg": "Article not found" }

GET /api/articles/:article_id/comments

Returns comments for a given article.

Example response

{
  "comments": [
    {
      "comment_id": 1,
      "votes": 16,
      "created_at": "2020-04-06T12:17:00.000Z",
      "author": "butter_bridge",
      "body": "Great article!",
      "article_id": 1
    }
  ]
}

Errors

  • 400 – { "msg": "Bad request" } (invalid article_id)
  • 404 – { "msg": "Article not found" }

POST /api/articles/:article_id/comments

Adds a new comment to an article.

Request body

{
  "username": "butter_bridge",
  "body": "Nice read!"
}

Example response

{
  "comment": {
    "comment_id": 999,
    "article_id": 1,
    "author": "butter_bridge",
    "body": "Nice read!",
    "votes": 0,
    "created_at": "2026-02-09T10:00:00.000Z"
  }
}

Errors

  • 400 – { "msg": "Bad request" } (missing/invalid fields)
  • 404 – { "msg": "Article not found" }
  • 404 – { "msg": "User not found" }

PATCH /api/articles/:article_id

Updates an article’s vote count.

Request body

{
  "inc_votes": 1
}

Example response

{
  "article": {
    "article_id": 1,
    "title": "Living in the shadow of a great man",
    "author": "butter_bridge",
    "body": "I find this existence challenging",
    "topic": "mitch",
    "created_at": "2020-07-09T20:11:00.000Z",
    "votes": 101,
    "article_img_url": "https://...",
    "comment_count": 11
  }
}

Errors

  • 400 – { "msg": "Bad request" } (invalid article_id or invalid/missing inc_votes)
  • 404 – { "msg": "Article not found" }

POST /api/articles

Adds a new article.

Request body

{
  "author": "butter_bridge",
  "title": "My new article",
  "body": "This is the article content...",
  "topic": "mitch",
  "article_img_url": "https://..."
}

article_img_url is optional and will default if not provided.

Example response

{
  "article": {
    "article_id": 999,
    "author": "butter_bridge",
    "title": "My new article",
    "body": "This is the article content...",
    "topic": "mitch",
    "article_img_url": "https://...",
    "votes": 0,
    "created_at": "2026-02-09T10:00:00.000Z",
    "comment_count": 0
  }
}

Errors

  • 400 – { "msg": "Bad request" } (missing/invalid fields)
  • 404 – { "msg": "User not found" } (author does not exist)
  • 404 – { "msg": "Topic not found" } (topic does not exist)

Comments

PATCH /api/comments/:comment_id

Updates the vote count for a comment.

Request body

{
  "inc_votes": 1
}

Example response

{
  "comment": {
    "comment_id": 1,
    "article_id": 1,
    "author": "butter_bridge",
    "body": "Great article!",
    "votes": 17,
    "created_at": "2020-04-06T12:17:00.000Z"
  }
}

Errors

  • 400 – { "msg": "Bad request" } (invalid comment_id or invalid/missing inc_votes)
  • 404 – { "msg": "Comment not found" }

DELETE /api/comments/:comment_id

Deletes a comment by ID.

Responds with status 204 and no content.

Errors

  • 400 – { "msg": "Bad request" } (invalid comment_id)
  • 404 – { "msg": "Comment not found" }

Error handling

Errors are returned in the format:

{
  "msg": "Bad request"
}

Status codes

  • 400 – Bad request (invalid id/query/body)
  • 404 – Resource not found
  • 500 – Internal server error

Common error messages

  • { "msg": "Bad request" }
  • { "msg": "Article not found" }
  • { "msg": "Topic not found" }
  • { "msg": "User not found" }
  • { "msg": "Comment not found" }
